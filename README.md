# Math-Quiz-Game
A interactive console-based Math Quiz Game written in C++ that generates arithmetic questions across various difficulty levels and mathematical operations.

# Features
- Custom Game Rounds: Choose how many questions you want to solve in a single match.

- Multiple Difficulty Levels:
  - Easy: Numbers between -10 and 10
  - Medium: Numbers between -50 and 50
  - Hard: Numbers between -100 and 100
  - Mix: Dynamically chooses a random difficulty for each question

- Arithmetic Operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)
  - Mixed (randomly assigns an operation per question)

- Real-time Feedback & Formatting: Immediate visual feedback with ANSI color highlighting for correct (Green) and wrong (Red) answers.

- Game Summary: Detailed end-of-game performance stats displaying win/loss state based on total correct answers versus incorrect answers.

# Requirements & Building
- OS: Cross-platform (Windows / Linux / macOS) console supporting ANSI escape sequences.

- Compiler: GCC / MinGW / Clang (C++11 or higher).

# How to Play
- copy and paste the code in your IDE or editor.

- run the code.

- Enter the total number of rounds you want to play.

- Select your desired difficulty level (1-4).

- Select the operation type you want to practice (1-5).

- Answer each arithmetic question presented on screen.

- Review your final results screen and decide if you want to play again.
